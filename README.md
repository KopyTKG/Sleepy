# sleepy

`sleepy` is a small [Odin](https://odin-lang.org/) CLI tool that converts an
**OpenAPI 3** JSON specification into an **Insomnia v4 export** JSON document
(`_type: "export"`, `__export_format: 4`).

It is a generalization of a project-specific Node script: it works with any
single OpenAPI 3 document and emits a generic bearer-auth collection driven by
two environment variables (`baseUrl`, `bearer`).

## What it produces

The export contains:

- A `workspace` resource (named after the spec's `info.title`).
- One `environment` resource named **"Base Environment"** whose `data` is
  `{ "baseUrl": "", "bearer": "" }`.
- One `request_group` (folder) per OpenAPI **tag** (the operation's first tag,
  or `default`), sorted alphabetically.
- One `request` per operation (`get`/`post`/`put`/`delete`/`patch`), each with:
  - a stable `_id` derived from `operationId` (or `<method>_<path>`), slugified
    and prefixed `req_`;
  - `name` = `"<METHOD> <path>"`, uppercase `method`;
  - `url` = `"{{ _.baseUrl }}<path>"`;
  - `parentId` = the tag folder's id;
  - a `Content-Type: application/json` header when the operation has a
    `requestBody`;
  - query `parameters` (from `parameters` where `in == "query"`);
  - bearer `authentication`: `{ "type": "bearer", "token": "{{ _.bearer }}" }`;
  - a `body` with a generated example JSON object when the request body has a
    `application/json` schema.

### Schema → example generation

Request-body examples are generated by recursively walking the JSON schema:

- `$ref` is resolved against the root document (`#/...`), with cycle guarding
  and a depth cap (~6).
- `allOf` merges all subschema objects; `oneOf`/`anyOf` use the first entry.
- `enum` uses its first value; an explicit `example` is used as-is.
- `string` → `""`; `format: date-time` → an ISO timestamp placeholder,
  `format: date` → an ISO date, `format: uuid` → the all-zero UUID.
- `integer`/`number` → `0`, `boolean` → `false`.
- `array` → `[ example(items) ]`.
- `object` (or unspecified) → an object of `property → example(property)`.

> Note: Odin has no easy "now", so date/date-time placeholders are fixed
> strings (`2020-01-01T00:00:00Z` / `2020-01-01`).

## Build

Requires the Odin compiler on your `PATH` (developed against
`dev-2026-06`).

```sh
# Debug / local build
odin build . -out:sleepy

# Optimized release build
odin build . -out:sleepy -o:speed -no-bounds-check
```

## Usage

```
sleepy <spec.json> [-o <out.json>]
sleepy -          [-o <out.json>]   # read the spec from stdin
```

- If `-o` is omitted, the export is written to **stdout**.
- If the input argument is `-`, the spec is read from **stdin**.
- On bad usage, a usage message is printed to stderr and the process exits
  non-zero.

### Examples

```sh
# From a file to stdout
sleepy openapi.json

# From a file to a file
sleepy openapi.json -o insomnia.json

# From a live endpoint via stdin
curl -s https://api.example.com/openapi.json | sleepy - -o insomnia.json
```

Then import the resulting `insomnia.json` in Insomnia via
*Import → From File*, and fill in the `baseUrl` and `bearer` values on the
"Base Environment".

## Scope

`sleepy` targets **OpenAPI 3** JSON documents. YAML specs are not supported;
convert them to JSON first (e.g. with `yq -o=json`).
